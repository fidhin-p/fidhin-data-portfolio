# Fidhin Data Portfolio

Build a premium, futuristic Data Analyst portfolio website for Fidhin.

DESIGN:
Use a dark black and charcoal background with subtle purple and blue accents, modern typography, smooth scrolling, elegant animations, glowing borders, and professional project cards. The design should look polished and premium, similar to a modern technology professional's portfolio.

Make the website responsive for desktop, tablet, and mobile.

HOMEPAGE:
Display:
"Hi, I'm Fidhin."
"Aspiring Data Analyst | Business Intelligence | Business Research"

Introduction:
"I combine data analytics, visualisation, and business research to turn information into meaningful insights that support better decisions."

Include buttons for "Explore My Work" and "Download My Resume".

ABOUT ME:
Create a professional section introducing me as an aspiring Data Analyst pursuing entry-level analytics opportunities in India.

SKILLS:
Create cards for Microsoft Excel, Power BI, SQL, and Tableau. Do not invent certifications or proficiency levels.

INTERNSHIP:
Company: Iqraa Mark Private Limited.
Role: Data Analytics Intern.
Location: Kozhikode, Kerala.

Allow me to add my actual internship dates and verified responsibilities.

Create a premium project page covering:

* Project overview and business objectives.
* Competitor research.
* Customer segmentation.
* Membership tier recommendations.
* Subscription pricing research.
* Revenue forecasting.
* Subscription management workflows.
* Business recommendations.
* Key learnings.

Clearly distinguish research findings, proposed recommendations, and implemented work.

PROJECT SHOWCASE:
Create attractive cards for Power BI dashboards, Excel analysis, SQL projects, and business research. Use placeholders until I upload real work.

CERTIFICATES:
Create a section for my internship experience certificate and internship completion certificate. Let me upload the actual certificates.

RESUME:
Create a download button that I can connect to my real resume PDF.

CONTACT:
Display my professional email: [fidhinp8@gmail.com](mailto:fidhinp8@gmail.com).
Include placeholders for LinkedIn and GitHub links.

TECHNICAL REQUIREMENTS:
Use a modern React-based frontend with clean, reusable components.
Make navigation functional.
Ensure accessibility and responsive layouts.
Keep the website lightweight and fast.
Use real project screenshots only when supplied.
Do not invent achievements, metrics, testimonials, or professional experience.

Build the complete initial website, not just a design mockup.
